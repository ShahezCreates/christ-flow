# CHRIST FLOW — Viva cheat sheet

### Why C?
C is the main language because the decision engine is responsible for numerical calculations, classification, comparison and recommendation logic.

### Where are conditions used?
Occupancy thresholds classify locations as LOW CROWD, MODERATE, BUSY, VERY BUSY or OVERLOADED.

### Where are loops used?
The C recommendation routine scans available options and finds the strongest flow score.

### Where are functions used?
Examples: `calculateOccupancy`, `calculateWaitMinutes`, `calculateFlowScore`, `calculatePriority` and `getStatus`.

### Where are strings used?
Location names and category values are strings; `strcmp` is used for category selection.

### Why HTML/CSS/JS?
The web stack is only the presentation and interaction layer. It visualizes values produced by the C engine.

### Is the data real?
No. The prototype uses simulated campus data. A production version would require an approved data-collection mechanism and privacy safeguards.
